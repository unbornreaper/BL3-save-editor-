PS5 / PS4 in 6 steps

  1. PS5: Settings → Saved Data → PS4 Games → Copy to USB drive (pick Borderlands 3).
  2. Plug the USB into your PC, open Save Wizard → select the BL3 save → Advanced Mode → Decrypt and export. You'll get files named like 2 (it's JSON text inside, and that's fine).
  3. Open the exported file here (character = 1.sav/2.sav…, bank/golden keys = profile.sav).
  4. Go nuts: GOD MODE, OP, MODDED, or just type what you want in the Lazy Box.
  5. Hit 💾 Save file → keep the same name (like 2) → import it back into Save Wizard (replace the decrypted file) → Encrypt / Re-sign to your profile.
  6. Copy the save back to the PS5 from the USB (Saved Data → PS4 → Copy to console). Done. 🔥

⚠ Keep a backup of your original save. Modded gear is for offline / solo fun — don't ruin other people's games.
